# ATM Simulator - Core Java  A console-based ATM Simulator built using Core Java to practice Object-Oriented Programming concepts through a real-world banking application. 
## Features  - PIN authentication with a maximum of 3 attempts - Multiple bank account support - Check account balance - Deposit money - Withdraw money with transaction validation - Transaction history using ArrayList - Change ATM PIN - Save updated PIN locally using file handling - Input validation for deposits and withdrawals - Menu-driven ATM interface  
## Technologies Used  - Java - Object-Oriented Programming (OOP) - Encapsulation - ArrayList and Collections - Exception Handling - File Handling - Git and GitHub  ## Concepts Practiced  - Classes and Objects - Constructors - Methods - Encapsulation - Conditional Statements - Loops - ArrayList - File Input/Output - Input Validation 
## How to Run  1. Clone or download this repository. 2. Open the project in Eclipse or another Java IDE. 3. Run `ATM.java`. 4. Select a bank account. 5. Enter the PIN and follow the on-screen ATM menu. 
## Learning Goals  This project was created to strengthen Core Java fundamentals and understand how OOP concepts can be applied to build a practical, menu-driven banking application.
